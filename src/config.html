How these sources work

ČHMÚ measurements and available ALADIN forecasts stay first. Open-Meteo fills missing fields only while completion is on. Neither UV option is an instantaneous measurement.

ČHMÚ UV is independent of the full-day forecast switch. To stop ČHMÚ app-service requests, turn full-day forecasts off and choose Open-Meteo or Hide UV.

The ČHMÚ app service receives the nearby forecast town's coordinates and a random ID made for this plugin installation. Open-Meteo receives the forecast town's coordinates. No personal sign-in is needed.

Turning a source off excludes its cached values too. A request already sent can finish; weather already stored by Pebble or another watchface is not retracted.

Setup and help

Use with Pebble

In Pebble, open Settings → Weather → Weather provider and select ČHMÚ Weather. Saved locations and units are used automatically.

For watchfaces that choose their own source, select ČHMÚ Weather there. Coverage follows nearby Czech forecast towns; Pebble can use its own fallback outside supported coverage.

Measurements and forecasts

The plugin prefers a station measurement less than one hour old and preserves its original time. Otherwise it uses a forecast; direct plugin readings mark that estimate with ~.

Humidity and wind prefer the same station and time as the temperature. Missing fields and future hours use forecasts. Feels-like is a calculated shade estimate, and sun times are calculated locally.

As Pebble's Weather provider, this plugin also feeds the watch's Weather app and timeline. Each refresh blends a fresh station reading into the current hourly slot. Pebble controls import timing and may discard estimate markers or source details.

The times on this page use your phone's time zone. Download time does not make a measurement newer.

Weather data: Český hydrometeorologický ústav (ČHMÚ) and, when enabled, Open-Meteo. Independent of these providers and Core Devices. No analytics or developer-operated server.
