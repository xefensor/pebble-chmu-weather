Unofficial Pebble plugin

ČHMÚ Weather

Measured temperature nearby. ALADIN forecasts for the hours ahead.

Use with Pebble

In Pebble, open Settings → Weather → Weather provider and select ČHMÚ Weather. Your saved weather locations and units are used automatically.

For apps that choose their own plugin, select ČHMÚ Weather in that app. Weather coverage follows nearby Czech forecast towns. Unsupported places can fall back to Pebble's own provider.

Full-day forecasts

Enabled by default. Uses full-day ALADIN summaries for the first three days, including the hours that have already passed today.

The ČHMÚ app service receives the nearby forecast town's coordinates and a random identifier created for this plugin installation. It is also used when you choose ČHMÚ UV below. The two choices are independent.

UV

ČHMÚ predicts UV at noon under clear skies. Open-Meteo forecasts the day's peak accounting for clouds. Neither is an instantaneous measurement.

Rain and longer local forecasts

Enabled by default. Adds rain probabilities and local forecast days beyond ALADIN's range, up to seven days. Supplies forecast peak UV when ČHMÚ app UV is unavailable. ČHMÚ remains the first choice for measured temperature and its available forecasts.

Open-Meteo receives the coordinates of the nearby forecast town. Turn this off to use only ČHMÚ weather data and local calculations.

What the temperature means

A station measurement less than one hour old is preferred. Its original measurement time is preserved.

If no suitable fresh measurement is available, the current ALADIN forecast is used. Direct plugin readings mark this estimate with ~.

Fresh station humidity and wind are preferred when measured with the temperature. Missing fields use forecasts. Conditions and future hours are forecasts. Feels-like is a calculated shade estimate; sun times are calculated.

When selected as Weather provider, these values also feed the watch's Weather app and timeline. Each refresh puts the same fresh station measurement into the current hourly slot and current temperature. Other hours stay forecasts. Pebble controls native Weather update timing and can discard estimate markers and UV source details.

Weather data: Český hydrometeorologický ústav (ČHMÚ) and, when enabled, Open-Meteo. This plugin is independent of these providers and Core Devices. No personal account, analytics or developer-operated server.
