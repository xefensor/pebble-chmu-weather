# ČHMÚ Weather support

Report problems at [GitHub issues](https://github.com/xefensor/pebble-chmu-weather/issues).
Include the plugin and Pebble phone app versions, saved/current location mode,
selected source options, the displayed observation time and reproduction steps.
Remove precise private locations and installation identifiers from reports.

Use the current Pebble phone app and enable Plugins / permissions preview.
Choose ČHMÚ Weather as the Weather provider or select its standard
`weather/location` source in a compatible consumer. Coverage follows Czech
stations and ALADIN forecast locations. Provider availability and Pebble's
refresh schedule affect delivery; receiving a value does not make an old
observation fresh. This independent plugin is not an official ČHMÚ app.

Published downloads remain on [GitHub releases](https://github.com/xefensor/pebble-chmu-weather/releases).
Local 1.0.2 candidates are not a published release. Personal builds are separate
and are not supported as part of the public Store package.
